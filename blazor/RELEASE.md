# RBushWeb.Blazor 0.2.0

Add .NET 8 / .NET 10 typed spatial-index services, stable-id insertion/removal, bulk loading, native intersection and nearest-neighbor queries, snapshots, a lifecycle provider and Razor-templated query component. Bundle the complete native RBushWeb exports without a CDN or npm requirement for consumers. Add functional WebAssembly and Interactive Server samples, package-consumer browser qualification and independently versioned NuGet/release publication.

The typed facade validates finite ordered envelopes; the generic native bridge retains access to specialized native envelope semantics and callback-based APIs.
